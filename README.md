# Vincent Yen Personal Website

This is my personal website for CSCE 331 Project 1. It includes information
about me, my projects, my qualifications, and my activities outside of school.

## Website Links

- Live website: https://people.tamu.edu/~vincentyen/
- Current GitHub repository: https://github.com/vincentyenn/CSCE-331-Lab-Personal-Website
- The final class repository should be uploaded to the TAMU GitHub organization
  with the name `project1-vincentyen`.

## Pages

- `index.html` - Home page with my introduction, photo, social links, and About Me section
- `portfolio.html` - Projects and links to their Devpost pages
- `qualifications.html` - Resume, technical interests, skills, education, and experience
- `extracurricular.html` - Videography, sports, music, travel, and other interests
- `sandbox.html` - An experimental galaxy page with interactive planets

The main pages use `styles.css`. The sandbox page uses its own CSS file so it
can have a different style.
